# AI Skills Library

A working library of AI skills for content and outbound operations — one small, single-purpose skill per task, browsable and searchable.

Each skill lives in its own folder under [skills/](skills/) as a `SKILL.md` file, using the standard [Claude Code skill format](https://docs.claude.com/en/docs/claude-code/skills): YAML frontmatter (`name`, `description`) followed by the skill's instructions.

## Skills

| Skill | Description |
| --- | --- |

| [idea-tournament](skills/idea-tournament/SKILL.md) | Runs competing ideas head-to-head to surface the strongest concept. |
| [proposal-creator](skills/proposal-creator/SKILL.md) | Turns a scoped opportunity into a structured proposal document. |
| [researcher](skills/researcher/SKILL.md) | Pulls sourced, cited research on a topic before a draft starts. |
| [results-scan](skills/results-scan/SKILL.md) | Pulls performance data on published content back into the pipeline. |
| [ship-scan](skills/ship-scan/SKILL.md) | Final pre-publish check for gaps, broken links, and missing assets. |
| [taste-filter](skills/taste-filter/SKILL.md) | Screens a draft against a house style bar and rejects the generic ones. |
