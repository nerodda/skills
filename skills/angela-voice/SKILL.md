# Angela Voice

Rewrites an existing draft in a named reference voice, changing how it sounds without changing what it says.

## When to use

Use this on a draft that already exists — from [[long-form]], [[newsletter-writer]], or any other drafting skill — once the content and structure are settled and the goal is specifically to transform its voice to match a named reference style. This is a voice-transfer pass, not a first draft: if there's no draft yet, draft it first. Don't use this to fact-check, restructure, or shorten a piece — that's a different pass; this one is about word choice, rhythm, and sentence-level style only.

## Inputs needed

Before rewriting, confirm:
- **The draft** — the existing piece to transform, in full
- **Voice reference** — a sample or set of samples written in the target voice, sufficient to infer its patterns (sentence length, rhythm, word choice, tone, quirks). Don't rewrite from a one-line description of the voice alone if actual samples are available — infer the pattern from the samples themselves.
- **Scope** — whether the whole piece gets the pass or only specific sections

If no voice reference sample is available, ask for one rather than guessing at a style from name or reputation alone.

## Preserve vs. transform

This is the core rule: change how it's said, not what's being said.

**Preserve, unchanged:**
- Every factual claim, statistic, and quote
- The argument's structure and order of points
- Any specific commitments (numbers, dates, promises) stated in the draft
- Section boundaries and overall length, unless the voice reference itself runs consistently shorter or longer

**Transform, to match the reference voice:**
- Word choice and vocabulary level
- Sentence length and rhythm (short punchy sentences vs. longer builds, per the reference)
- Sentence-opening patterns and transitions
- Tone markers — where the reference is direct, blunt, wry, formal, etc., match it
- Idiosyncratic phrasing patterns evident in the reference sample (recurring constructions, favorite transitions, characteristic asides)

If a claim in the draft seems to need changing to "sound right" in the new voice, that's a sign the rewrite has drifted into content edits — stop and flag it instead of silently altering meaning.

## Output format

The full draft rewritten in the reference voice, same length and structure as the input unless the voice reference itself justifies a shift. Flag any spot where matching the voice created tension with preserving a specific claim, so the human can decide how to resolve it.
