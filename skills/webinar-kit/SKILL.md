# Webinar Kit

Builds the complete set of assets needed to run one webinar — promotional copy, the presentation script, and the post-event follow-up sequence — as a coordinated bundle anchored to a single event.

## When to use

Use this once a webinar has a topic, date, and speaker locked in. It's event-anchored the same way [[launch-video]] is anchored to a single launch, but it produces a kit of multiple asset types rather than one script — promo copy, a script, and a follow-up sequence all built around the same event so they stay consistent with each other. If only the follow-up emails are needed and promo/script already exist elsewhere, draw on [[lead-magnet-engager]]'s sequence-writing approach instead of running the full kit.

## Inputs needed

Before drafting, confirm:
- **Topic and core promise** — what attendees will walk away knowing or able to do
- **Date, time, and registration link/mechanism**
- **Speaker(s)** — name, role, and one credibility line each
- **Target audience/ICP** — who this webinar is for
- **Promo channels** — where the promo copy needs to run (email, LinkedIn, X, etc.)
- **Offer at the close** — what's pitched at the end of the webinar, if anything, so the script and follow-up build toward the same ask

If the closing offer is undecided, ask — a webinar script and follow-up sequence without a defined next step end anticlimactically.

## Kit structure

Produce three coordinated asset sets, all referencing the same core promise so they read as one campaign rather than three unrelated pieces:

1. **Promo copy** — one registration-page/landing copy block plus one promo post per channel specified. Each piece leads with the core promise, not the topic name, and ends with a direct registration CTA.
2. **Presentation script** — a section-by-section outline (not a verbatim word-for-word script) covering: hook/open, 2–4 content sections each with one core takeaway, a mid-point engagement moment (poll/question), and a close that transitions cleanly into the offer. Mark timing estimates per section.
3. **Follow-up sequence** — 3 emails: same-day recap + replay link (for both attendees and no-shows, noted separately), a value-reinforcement email a few days out, and a final offer-close email tied to the same ask made live. Follows the same warm, already-engaged tone as [[lead-magnet-engager]]'s sequence, since a webinar registrant is a warm lead, not a cold one.

Rules:
- The core promise stated in the promo copy must be the exact thing delivered in the script — never promo a broader promise than the content covers.
- No-show follow-up and attendee follow-up must differ: no-shows need the replay pushed harder; attendees need the offer pushed harder.
- Keep the script an outline of talking points and transitions, not a word-for-word read — a live presenter needs cues, not a script to recite.

## Output format

Three labeled sections in this order — Promo Copy, Presentation Script, Follow-Up Sequence — each internally structured per the rules above, with a one-line note at the top restating the core promise all three sections build toward.
