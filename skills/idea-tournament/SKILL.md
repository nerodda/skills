# Idea Tournament

Compares two or more candidate ideas for the same slot head-to-head and returns a single winner, so effort doesn't get split across ideas that are competing for the same spot.

## When to use

Use this once multiple ideas exist for one channel/audience/moment and a choice has to be made between them — after each candidate has already cleared [[idea-review]] individually, since this skill picks a winner, it doesn't screen for a minimum bar. If only one idea is on the table, this isn't the right skill.

## Inputs needed

- **The candidate ideas** — two or more, each as a one- or two-sentence statement
- **The shared slot** — the channel, audience, and moment they're all competing for (if they're not actually competing for the same slot, they don't belong in the same tournament)

## Comparison criteria

Judge every matchup on the same four axes. Don't average them into a single number — reason about the pair directly.

- **Differentiation** — which take says something the audience hasn't already heard from this account or its peers?
- **Timeliness** — which one is more urgent or relevant right now, versus evergreen and fine to run anytime?
- **Executability** — which is more likely to land well given the format, resources, and time actually available?
- **Audience pull** — which is more likely to get read, watched, or shared by the people this is actually for?

## Method

- **Two ideas:** run a single direct comparison across the four criteria and declare a winner.
- **Three or more ideas:** run single-elimination pairwise matchups until one idea remains. Don't rank all ideas on one combined scale — a head-to-head per pair surfaces sharper reasoning than a leaderboard does.
- **Tie-break:** if a matchup is genuinely even after all four criteria, timeliness wins the tie — a good idea that's late is worse than a slightly less polished idea that's on time.

## Output format

For each matchup:
1. The two ideas being compared
2. One line per criterion naming which idea it favors (or "even")
3. The matchup winner, with the one deciding criterion named

At the end of the tournament:
1. **Winner** — the surviving idea, stated plainly
2. **Why** — the one or two criteria that actually decided it, not a recap of every matchup
3. **Runners-up** — note anything strong that lost only on timeliness or slot-fit, so it isn't lost — it may be the winner for a future slot
